# My Skill Module (template)

1. Copy this folder: `modules/_template_skill` → `modules/my_module`.
2. Edit `module.json`: set `id` to `my_module` (must match the folder),
   your name, description, capabilities, permissions and examples.
3. Edit `skill.py`: write your `@register` skill(s).
4. Write this README: what it does, examples, permissions.
5. In the MODULES tab, press **ACTIVATE** — or check it first with
   **CHECK** pointed at the folder.

If anything is wrong, the module shows as **FAILED** with the exact
reason. Nothing loads without your say-so.

Full author guide: `MODULES.md` in the repo root.
