Why people keep it running

Three things JARVIS does that browser assistants can't.

🎙️

Voice-first, instant

Over 100 local skills answer in under a second — no round trip, no key required. Alt+Space summons it over any window; the mic is one button.

🏠

Local-first, honest

Your memory, notes and keys stay on your PC. One status pill always tells the truth — READY, ATTENTION or SAFE MODE — and a degraded feature says so instead of failing silently.

🧩

Yours to extend

Every skill is a small Python file you can read, tweak or add. 18 one-click skill packs and 12 MCP servers in the built-in library. MIT licensed — fork it, own it.

Install in 3 steps

Windows 10/11. Existing files are never touched.

Run the one-liner

Paste into PowerShell or cmd — it clones, builds the environment and runs an 11-point health check.

powershell -c "iex (irm https://raw.githubusercontent.com/Youssef-Devolopment/jarvis/main/setup.ps1)"

Add your AI key (optional)

Start JARVIS once, open Settings → GENERAL, paste your DEEPSEEK_API_KEY (any OpenAI-compatible provider works). Skip it and you're already in skills-only mode — 100+ commands, no key.

Launch and talk

Double-click desktop.bat — tray icon, hotkeys and the Alt+Space HUD. Say "open notepad", "what time is it", "remind me to stretch in 20 minutes".

Full guide, configuration and troubleshooting in the README.
